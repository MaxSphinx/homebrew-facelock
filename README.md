# Homebrew Tap for FaceLock 🍺 🛡️

Official Homebrew tap for **[FaceLock](https://github.com/MaxSphinx/FaceLock)** — Native biometric application shield and intruder defense for macOS.

## Installation

```bash
# Add the tap
brew tap MaxSphinx/facelock

# Install FaceLock
brew install --cask facelock
```

Or install directly in one command:

```bash
brew install --cask MaxSphinx/facelock/facelock
```

## Update

```bash
brew upgrade --cask facelock
```
